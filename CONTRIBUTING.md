# Contributing

Thank you for the interest — but **outside contributions are not being accepted yet.**

lore is maintained under sole copyright so that licensing decisions remain open,
including the eventual conversion to Apache 2.0 and any alternative licensing
arrangement. Accepting a pull request without a contributor licence agreement in place
would close that door permanently, so no CLA means no merges. A CLA will be put in
place before contributions are opened.

In the meantime:

- **Bug reports are welcome and useful.** Open an issue.
- **Questions and design discussion are welcome.** Open an issue.
- **Pull requests will be closed unmerged**, however good they are. Please don't spend
  your time on one.

Forking is of course permitted under the licence.

## Security

Please do not open a public issue for a security problem — especially anything touching
key custody, space isolation, the sync/signing path or the relay. Contact the maintainer
directly.
